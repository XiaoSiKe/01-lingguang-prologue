# 零一 AI 日新社 · Harness 视觉

这是在个人电脑中开启编程工作区的黑白机械界面。启动演出承担仪式感，工作台让使用者专注阅读、输入与审查。

- 黑色 `#000000` 为演出底色，工作台以 `#0a0a0a` / `#151515` 区分层次；白色 `#f2f2f2` 承担主信息，中灰 `#a3a3a3` 承担辅助文字。状态同时用文字与形状表达。
- 中文和英文使用 Helvetica Neue、PingFang SC 与现有本地字体的回退组合；数字与协议使用系统等宽字体。关键标题加粗，主要按钮至少 44px 高。
- 原始银灰 Logo 只等比展示和裁去空白。开场与终幕逐字保留「从零到一，让技术进步成为每个人的机会！」。
- 保留原仓库 DELTA CIRCUIT 三角构造，直接使用上游三块三角主体的原始多边形，保留断开的边轨、阶梯底边与三角定位线；社团银灰 Logo 融入中央负空间，取消方形承载座、支撑梁与额外装甲块。取消圆环。启动／确认时快速运动、减速、闭合；日新社原 Logo 位于三角中心和左上角品牌区，初心标语在开场和终幕加粗呈现，三角主体与文字保持清晰。拖动转向与数字键焦点继续使用上游控制器。
- 身份页在桌面上分开徽记与资料；手机优先展示可操作的身份卡。能力读取面板由真实 DOM 布局测量定位，数据来自上游 API。
- 不做假的加载百分比、技能数量或模型回复。离线预览明确提示未连接本机服务。
- 减少动态效果时使用固定机械构图，不依赖动画才能显示内容。

动效真源为 `docs/startup-visuals.js` 与 `docs/startup-sequence.js`。品牌层直接调用上游渲染器，不另写三角拼装、扫描或转场时间线；品牌适配限于黑白配色、社团 Logo、文案、排版与沿原标识轮廓的轻微刻线。

主要实现：`docs/startup-rixin.css`、`docs/startup-rixin.js`、`web/src/rixin-theme.css`。保留 `rhine` / `laterano` 后端风格协议，本版 `rhine` 对应零一黑白机械。
